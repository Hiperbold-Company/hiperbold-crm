Política de Privacidade

Última atualização: 14 de outubro de 2026

Esta Política de Privacidade explica como Filipe José de Oliveira Lima Ltda. (nome fantasia Hiperbold Company), inscrita no CNPJ sob o nº 37.267.482/0001-50, com sede em Rua Rio de Janeiro, 243, Sala 802, Centro, Belo Horizonte/MG, CEP 30160-040 ("Hiperbold", "nós"), trata os dados pessoais no HiperCRM, em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018, "LGPD").

1. Controlador dos dados

Para os dados pessoais tratados na plataforma HiperCRM, o controlador é a empresa cliente que contrata o serviço (a empresa que usa o CRM para atender seus próprios clientes). A Hiperbold atua como operadora, processando os dados em nome e conforme as instruções do cliente. Para os dados dos próprios usuários da plataforma (quem faz login no HiperCRM), a Hiperbold atua como controladora.

2. Dados que coletamos

Coletamos: dados de cadastro (nome, e-mail, telefone, empresa); dados de uso da plataforma (login, ações no funil, configurações); conteúdo das conversas de WhatsApp e do funil de vendas, inseridos pelo cliente ou pelos contatos dele; dados de pagamento processados pelo Asaas (a Hiperbold não armazena número de cartão); dados técnicos (endereço IP, navegador, registros de acesso).

3. Finalidades do tratamento

Usamos os dados para: viabilizar o funcionamento do CRM (funil, WhatsApp, automações, agente de IA); autenticar o acesso e manter a segurança da conta; processar pagamentos; dar suporte técnico; cumprir obrigações legais e regulatórias; melhorar a plataforma.

4. Bases legais

O tratamento se baseia, conforme o caso, em: execução de contrato (para operar o CRM contratado); cumprimento de obrigação legal ou regulatória; legítimo interesse (para segurança e melhoria do serviço); consentimento, quando exigido, em especial para o contato feito pelo agente de IA com os clientes finais da empresa contratante.

5. Compartilhamento de dados

Compartilhamos dados com operadores que apoiam a operação do HiperCRM, entre eles: provedor de nuvem, onde os dados são armazenados; provedor de inteligência artificial, para processar as mensagens e gerar as respostas do agente; Asaas, para processamento de pagamentos; e a Meta, quando o cliente conecta o WhatsApp pela API oficial. Não vendemos dados pessoais a terceiros.

6. Retenção dos dados

Mantemos os dados pelo tempo necessário para cumprir as finalidades descritas acima, para atender obrigações legais e enquanto durar a relação contratual com o cliente. Depois do cancelamento, os dados da conta ficam disponíveis por 90 dias para que o cliente possa exportá-los; passado esse prazo, são excluídos ou anonimizados. Registros que a lei obriga a guardar, como os fiscais e os de acesso, são mantidos pelo prazo legal (5 anos para os fiscais e 6 meses para os registros de acesso, conforme o Marco Civil da Internet).

7. Direitos do titular

Nos termos da LGPD, o titular dos dados pode solicitar: confirmação da existência de tratamento; acesso aos dados; correção de dados incompletos ou desatualizados; anonimização, bloqueio ou eliminação de dados desnecessários; portabilidade; eliminação dos dados tratados com consentimento; informação sobre compartilhamento; e revogação do consentimento. Pedidos relacionados aos clientes finais atendidos por uma empresa que usa o HiperCRM devem ser encaminhados primeiro a essa empresa, controladora desses dados.

8. Segurança

Adotamos medidas técnicas e administrativas para proteger os dados pessoais contra acessos não autorizados e situações de destruição, perda, alteração ou vazamento.

9. Encarregado de dados (DPO)

Para exercer seus direitos ou tirar dúvidas sobre esta política, entre em contato com o encarregado de dados: Filipe José de Oliveira Lima, pelo e-mail oliveira@hiperbold.com.br.

10. Alterações desta política

Podemos atualizar esta Política de Privacidade periodicamente. Alterações relevantes serão comunicadas por e-mail ou dentro da plataforma.

11. Contato

Dúvidas sobre esta política podem ser enviadas para oliveira@hiperbold.com.br.

titulo: Chave de API em "só os meus" não mostra mais a última mensagem das conversas dos colegas
---

Numa empresa configurada para cada atendente ver só os próprios atendimentos, uma chave de API de atendente que listava os contatos recebia junto a última mensagem da conversa de cada contato, inclusive das conversas de outros atendentes. Agora essa chave continua listando os contatos, mas sem a conversa. Chaves de gerente ou administrador, os outros modos de visibilidade e o uso pela tela seguem iguais. Integração que precisa da conversa nesse modo usa uma chave de gerente.

titulo: Reconectar pelo QR Code uma conexão de WhatsApp que caiu
---

Na aba da API não oficial, em Conexões, o cartão de uma conexão que não está conectada ganhou o botão "Reconectar". Ele mostra um QR Code novo (ou um código para digitar no celular) para a MESMA conexão: nada é apagado, nenhuma conexão nova é criada e a vaga do plano não muda. Se o QR expirar, é só gerar outro. Quando o número volta, a etiqueta passa a "Conectado", a faixa vermelha do topo some e, se o número que conectou for diferente do anterior, a tela avisa. Com uma conexão só caída, o botão "Escanear o QR" da faixa vermelha leva direto ao cartão dela, já com o QR aberto. Nada precisa ser mudado para atualizar.
